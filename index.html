سياسة الخصوصية

Khayal AI يحترم خصوصيتك. عند استخدام أداة توليد الصور، يتم إرسال النص الذي تكتبه إلى خادم التوليد لمعالجة طلبك وإنشاء النتيجة.

لا نطلب منك إدخال معلومات شخصية لإنشاء المحتوى، ولا نطلب منك إدخال مفاتيح API داخل الموقع.

الصور الناتجة يتم عرضها لك داخل المتصفح، ويمكنك حفظها على جهازك. ننصحك بعدم إدخال معلومات شخصية أو سرية داخل أوصاف التوليد.

قد يتم تحديث سياسة الخصوصية مستقبلاً عند إضافة خدمات جديدة مثل توليد الفيديو المتقدم أو تسجيل الحسابات.
